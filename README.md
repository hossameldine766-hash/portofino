# 🛍️  portofino System

نظام إدارة حسابات البازارات متكامل تم تطويره بلغة Python.

## 🌟 مميزات البرنامج (Features)
* إدارة الفواتير والمبيعات.
* إدارة المصاريف.
* تقارير مالية شاملة.
* واجهة مستخدم سهلة وبسيطة.

## 🛠️ التقنيات المستخدمة (Technologies)
* اللغة: Python
* واجهة المستخدم: Tkinter (أو اسم المكتبة التي استخدمتها)
* قاعدة البيانات: SQLite

1. قم بتثبيت متطلبات التشغيل:
   pip install -r requirements.txt
2. قم بتشغيل الملف الرئيسي:
   python porto3.py
